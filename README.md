# PTerm for modern macOS (Apple Silicon and Intel)

A build of [PTerm](https://www.cyber1.org/pterm.asp) 6.0.4, the PLATO
terminal emulator by Paul Koning, Joe Stanton and Dale Sinder, that runs on
current macOS versions, natively on Apple Silicon Macs (M1 and later).

The official PTerm 6.0.4 for Mac is an Intel-only build of 2018. This one
is a **universal binary** (arm64 + x86_64) for **macOS 11 Big Sur and
later**, built from the unmodified PTerm 6.0.4 source with current
libraries: wxWidgets 3.2, SDL2 and libsndfile, all linked in, so there
is nothing else to install.

Use it to connect to [CYBER1](https://www.cyber1.org/) (cyberserv.org)
and to [IRATA.ONLINE](https://irata.online/).

## Download and install

1. Download `Pterm-6.0.4-macOS-universal.zip` from the
   [Releases](../../releases) page and unzip it.
2. Move `Pterm.app` to the Applications folder.
3. The app is not notarized by Apple, so the first time macOS will refuse
   to open it. Either:
   * right-click (or Ctrl-click) `Pterm.app`, choose **Open** and confirm, or
   * run once in Terminal: `xattr -dr com.apple.quarantine /Applications/Pterm.app`

   (On macOS 15 Sequoia and later: try to open it once, then go to
   System Settings → Privacy & Security and click **Open Anyway**.)

## Window size

As in every PTerm version, the window size follows the **View** menu:
with a fixed zoom (*Zoom display 0.5x … 3.0x*) the window keeps its size;
choose **View → Keep aspect ratio** (square PLATO screen) or **View →
Stretch display** to resize the window freely, or **View → Full Screen**.

## Building

Requirements: Xcode command line tools and cmake (`brew install cmake`).

    ./build.sh

The script downloads and builds wxWidgets, SDL2 and libsndfile as static
universal libraries (the first run takes a while), builds PTerm from
`pterm-6.0.4/` and creates `dist/Pterm-6.0.4-macOS-universal.zip`
(ad-hoc signed).

## Changes from the original source

`pterm-6.0.4/` is the unmodified source kit from
[cyber1.org](https://www.cyber1.org/download/linux/pterm-6.0.4.tar.bz2).
The only additions, in `mac/`, are:

* `fixmenu.cpp`: an empty `fixmenu()`. PTerm calls it at startup on the
  Mac; its original source (`fixmac.m`) is not part of the published kit,
  and wxWidgets 3.2 sets up the macOS application menu by itself.
* `Info.plist.in`, and an application icon (`Pterm.icns`) that shows
  "PTerm" in the PLATO character set taken from PTerm's own font tables
  (`make_icon.py`).
* `wxversion.h` is generated by `build.sh` (wxWidgets version and build
  date, shown in the About box).

This makes it an altered source version in the sense of the PTerm license.
